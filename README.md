
# DeepSeek 联网流式对话（本地版） 一套面向 Windows 本地的轻量级 DeepSeek 流式对话系统，采用 **FastAPI 后端 + 轻量多源联网检索 + 原生单页前端 + VBS 无黑框静默启动** 架构，支持多会话管理、浏览器 `localStorage` 本地历史留存以及实时时间同步。 
## 核心特性 - 
**流式响应输出**：基于 SSE / 流式读取后端转发的 DeepSeek 响应，边生成边渲染，减少等待感。 
**轻量多源联网检索**：无需笨重的浏览器自动化驱动，通过轻量请求与关键词扩充整合搜索结果，为模型补充时效信息。 
**多会话与本地持久化**：左侧支持新建对话、切换会话、重命名、单条删除与清空；聊天记录保存在当前浏览器 `localStorage` 中，关闭或刷新页面不丢失。 
**静默一键启动**：通过 `启动.vbs` 在后台隐藏窗口拉起后端服务，并自动拉起前端网页，日常使用没有多余黑框干扰。 
**密钥后端隔离**：API Key 仅在后端使用，不写入前端页面或浏览器存储中。 

2. 配置 启动.vbs 中的 Python 路径

由于不同电脑上 Python 安装路径不同，需将 启动.vbs 中的 pythonExe 修改为本机实际路径。

打开命令行（Win + R 输入 cmd 回车），执行以下命令查看路径：where python 

打开 启动.vbs，修改对应路径：pythonExe = "你的本机\python.exe路径" 


3. 安装 Python 依赖

请确保本机已安装 Python 3（建议 3.10 及以上版本），并在终端安装所需依赖包：

**pip install fastapi uvicorn 
注：如果你本地的 server.py 中还引入了其他第三方库（如网络请求或解析库），请一并安装。

使用与维护

启动服务

直接双击运行 启动.vbs：

脚本会在后台以隐藏窗口方式启动 server.py（默认监听 http://127.0.0.1:8000）。

稍等约 1.5 秒后自动打开前端页面，即可开始对话。

停止服务

因为后端是静默在后台运行的，没有控制台窗口：

按 Ctrl + Shift + Esc 打开任务管理器，在进程列表中找到对应的 python.exe，结束该进程即可停止后端。

修改代码后的生效方式

修改了 server.py：必须先结束旧的 python.exe 进程，再重新双击 启动.vbs，否则端口仍会被旧进程占用，新代码不会生效。

修改了 deepseek网页版.html：直接在浏览器中刷新页面（F5 或 Ctrl + R）即可生效。

常见问题排查

网页打开后发消息没反应 / 提示请求失败

检查后端是否成功启动：可在命令行手动运行 你的python.exe路径 你的server.py路径 查看是否有报错。

检查 8000 端口是否被其他程序占用，或确认 server.py 中填的 API Key 是否有效。

双击 启动.vbs 没反应或报错

确认 启动.vbs 中的 pythonExe 路径拼写无误，且不要漏掉双引号。

若包含中文或特殊字符，保存 .vbs 时建议注意编码兼容（ANSI 或按系统默认编码保存）。

换个浏览器或清理浏览器缓存后历史记录没了

历史对话存储在浏览器的 localStorage 中，属于当前浏览器本地数据，不会跨浏览器或跨设备同步；清理站点数据时会被一并清除。
